Phase 02
Domain Modeling & Visitor / Double-Dispatch Pattern

Decoupled trade capture objects (EuropeanOption, Forward, InterestRateSwap) from mathematical pricing engines using double dispatch.

Instrument.accept(PricingEngine) → PricingEngine.visit_instrument(Instrument, MarketData)

Why it matters: Allows Independent Model Review (IMR) to switch valuation algorithms (e.g. Black-Scholes to Local Volatility) with zero changes to booking records or downstream trade models.

Phase 03
Analytical Black-Scholes-Merton Pricing Engine

Exact closed-form Black-Scholes valuation with continuous dividend yields $q$ and analytical Greeks:

d1 = [ln(S/K) + (r - q + 0.5*σ^2)T] / (σ√T)
d2 = d1 - σ√T
Call = S * exp(-qT) * N(d1) - K * exp(-rT) * N(d2)
Put = K * exp(-rT) * N(-d2) - S * exp(-qT) * N(-d1)
Phase 04
Yield Curve Bootstrapping & Multi-Curve Discounting

Calibrates discount curves from money market cash deposits and par swap quotes using log-linear discount factor interpolation and SciPy root solving.

P(0, t) = P(0, t_i) * [P(0, t_{i+1}) / P(0, t_i)] ^ [(t - t_i) / (t_{i+1} - t_i)]
⇒ Piecewise-constant instantaneous forward rate: f(t) = [ln P(0, t_i) - ln P(0, t_{i+1})] / Δt > 0
Phase 05
Linear Interest Rate Swaps & Multi-Curve DCF Engine

Evaluates fixed and floating legs with cashflow schedules, calculating the exact analytical par swap rate:

Par Swap Rate = [P(0, t_0) - P(0, t_n)] / ∑ [τ_i * P(0, t_i)]
Phase 06
Vectorized Monte Carlo Simulation with Antithetic Variates

Stochastic path simulation under risk-neutral measure with antithetic variance reduction and 99% confidence bounds:

S_T^{(1)} = S_0 * exp[(r - q - 0.5σ^2)T + σ√T * Z]
S_T^{(2)} = S_0 * exp[(r - q - 0.5σ^2)T - σ√T * Z]
SE = exp(-rT) * [s_Y / √N] ⇒ 99% CI: [μ - 2.58*SE, μ + 2.58*SE]
Phase 07
First & Second-Order Sensitivities (Greeks & DV01)

Central finite-difference sensitivities (Δ, Γ, Vega, Theta, Rho) and 1 basis point parallel curve DV01:

Delta = [V(S + ΔS) - V(S - ΔS)] / (2 * ΔS)
DV01 = V(r) - V(r + 1bp)
Phase 08
Fair Value Adjustments (XVA & Reserves) Framework

Configurable balance sheet reserves and adjustments with deterministic SHA-256 audit hashing:

1. Bid-Offer Reserve = 0.5 * |Net Delta * Spot| * Spread
2. FVA = ∑ [ EE+(t_m) * s_F * P(0, t_m) * Δt_m ]
3. CVA = (1 - R) * ∑ [ EE+(t_m) * PD(t_{m-1}, t_m) * P(0, t_m) ]
